Informática e Eletrônica

1.1 Componentes Internos

1.1.1 CPU

A CPU é o cérebro do computador, responsável pelo processamento de informações e execução de instruções.

1.1.2 Armazenamento

Dispositivos de armazenamento são responsáveis por guardar informações de forma temporária ou permanente.

1.1.3 Memória

A memória RAM permite o armazenamento temporário de dados para acesso rápido pelo processador.

1.1.4 Fonte de Alimentação

A fonte de alimentação converte a energia elétrica para fornecer a tensão adequada aos componentes do computador.

1.2 Componentes Externos

1.2.1 Teclado

O teclado é um dispositivo de entrada utilizado para digitação e interação com o sistema.

1.2.2 Monitor de Vídeo

O monitor exibe informações visuais do computador, permitindo a interação do usuário com o sistema.

2. Grandezas Elétricas

2.1 Potência Elétrica

A potência elétrica mede a taxa de consumo de energia de um circuito elétrico.

2.2 Tensão Elétrica

A tensão elétrica é a diferença de potencial entre dois pontos de um circuito elétrico.

3. Unidades de Medida na Informática

3.1 Capacidade de Armazenamento

A capacidade de armazenamento mede a quantidade de dados que um dispositivo pode guardar.

3.2 Frequência

A frequência mede a quantidade de ciclos de uma onda por segundo e é expressa em Hertz.
